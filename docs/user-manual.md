# cli-fp user manual

This page remains as a stable starting point for existing links. The v1.5.1
documentation is organized by the job you want to do rather than as one long
manual.

## Start here

- [Your first cli-fp program](getting-started.md) — compile the smallest root
  command and understand its three moving parts.
- [Commands and subcommands](commands.md) — choose a root, named, or nested
  command shape.
- [Options and validation](options.md) — register and retrieve supported
  parameter types.

## Find an answer

- [How do I...?](how-to.md) — concise recipes for common tasks.
- [Output, errors, and progress](terminal.md) — colours, spinners, progress,
  and exit codes.
- [Shell completion](completion.md) — generate Bash and PowerShell scripts.
- [Current limitations and gotchas](limitations.md) — supported boundaries
  before you design around an assumption.

## Look up or maintain

- [Runnable examples](examples.md) — compare a working program by goal.
- [Generator guide](codegen.md) — scaffold and regenerate a larger project.
- [API reference](api-reference.md) — signatures and contracts.
- [Technical documentation](technical-docs.md) — architecture and maintainer
  material.

When documentation and source disagree, the public units in `src/` and their
tests are authoritative.
