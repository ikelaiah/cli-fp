# Release Notes - cli-fp v1.4.3

`v1.4.3` is a documentation-infrastructure maintenance release.

## Historical documentation

- GitHub Pages now uses DocKit v1.0.0 historical publishing.
- Readers can select supported cli-fp releases and receive pages built from
  each release's immutable source, including legacy releases that predate
  DocKit configuration.
- The prior single-version `latest` Pages decision is recorded as superseded.

No cli-fp runtime, parser, completion, generator, or public API behaviour
changed in this release.
