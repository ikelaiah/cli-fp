# Release Notes - cli-fp v1.4.0

`v1.4.0` is a documentation and developer-learning release. It does not add a
new runtime API or change the supported class-based command model.

## What is new

- A focused first-CLI guide and a compiling `QuickStartDemo`.
- A task-oriented [How do I...?](how-to.md) guide for common application work.
- Focused guides for commands, options, terminal UX, shell completion, and
  current limitations.
- Intent-oriented DocKit navigation that separates learning, reference, and
  maintainer material.
- The existing Windows and Linux cleanup smoke checks now compile the
  QuickStartDemo, protecting the homepage example from drift.

## Roadmap update

The planned beginner callback API and typed argument access move to v1.5.0.
Application-core boundary work moves to v1.6.0. The v2.0.0 intent is unchanged.

## Upgrade notes

No source migration is required. Existing applications, generator projects,
and the public runtime API remain unchanged.

See the [changelog](../CHANGELOG.md) for the complete release history.
